# Unslop

Adapted for Codex from Unslop by Damir Sokolovsky ([@heydamir](https://x.com/heydamir)), licensed CC BY 4.0. Keep this credit and the retained LICENSE when copying or adapting the skill. The original method is [UPSTREAM_SKILL.md](UPSTREAM_SKILL.md).

## Scope

Refine an existing screen. Follow the user's references, product identity and design system. Preserve its features, labels needed for understanding, real claims, data and section order unless their change is requested. A functional status badge or brand gradient is not a defect merely because a reference discourages it.

New interfaces and broad art direction belong with frontend-design or an explicitly requested taste-skill workflow. Independent accessibility or production audits belong with impeccable-audit. Do not stack these workflows for an ordinary polish request.

## Work

1. Inspect the running interface and its current source. Read [the signs checklist](references/signs.md) as diagnostic prompts. Identify concrete problems and choose light polish or broader refinement from the evidence. If the screen already meets the brief, report that and stop.
2. Derive a short direction from the product, audience and supplied identity: product, character, world, meaningful visual moments if needed, and one distinctive detail if appropriate. Continue within existing authorization; clarify only a consequential ambiguity.
3. Apply the useful passes from the original method: spacing, color, icons, copy, type, layout, details, visuals and motion. Fix observed issues; do not force a change in every category. Existing project tokens come first. The [token reference](references/tokens.md) supplies examples when the project leaves a choice, not a universal palette, font, weight, grid or prohibition.
4. Preserve working interactions, focus and reduced-motion behavior. Keep semantic colors and meaningful states. Do not invent data, remove real constraints or replace useful density with empty space.
5. Inspect fresh desktop and narrow-screen renders of the changed source. Check the affected interactions and the project's ordinary tests. Deliver the working code, concise findings and actual verification, including remaining limits. Retain the original until the replacement works.

Read the relevant complete passes in UPSTREAM_SKILL.md for detail. Its style recipes, reference compositions and render-count examples are adaptable guidance; this Codex entry and the actual user brief control the task. Read [visuals](references/visuals.md), [reference images](references/refs.md) or [effects](references/effects.md) only when the requested work needs those treatments. No scene, generated image, ornament or story video is required for a complete result.
