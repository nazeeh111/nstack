# Five-lens council

Independently authored map of Remy's general-decision method. Read the complete privately fetched original before using the native substitutions. It keeps five drafts and five **fresh** reviewers; it does not copy the source prompt or require five simultaneous children.

## Frame and draft

Define the real decision, available alternatives, supplied facts and constraints. Do not give the panel the lead's preferred conclusion. Select all five methods before seeing outputs:

| Lens | Concrete operation |
| --- | --- |
| Contrarian | Construct the strongest plausible failure case and identify the fact that would establish or defeat it. Do not invent a defect. |
| First principles | Separate the desired outcome from the proposed solution; test which assumptions are necessary. |
| Expansionist | Identify overlooked upside or an adjacent option, stating its dependencies and resource implications. |
| Outsider | Read only the minimal shared packet; expose unexplained terms, assumed knowledge and unclear value. |
| Executor | Map a feasible first step, ownership, dependencies and an observable check. A plan is not permission to execute it. |

Use the actual source first-position prompt with the native substitutions in `SKILL.md`, one fresh context per lens, 150-300 words each unless a consequential detail needs more. Each gets the same neutral facts and only its assigned method. Host-sized waves are allowed; no answer crosses between draft contexts. Keep supported uncertainty instead of commanding absolute certainty or blindness to risk.

## Five fresh reviews

Collect all five real drafts. If one fails, record the gap; do not invent its output or label a smaller panel full. A partial review can still help, but the five-by-five run remains incomplete.

The faithful source route assigns a randomized shared A–E mapping, then gives all five anonymized responses and the neutral question to five new reviewer contexts. Retain the private mapping with the coordinator. Each reviewer answers the source's three questions: strongest response and why; response with the biggest blind spot and what is missing; and what all five missed. Keep each review under 200 words. No reviewer is an original author's retained context. Do not name draft lenses or show other reviews. A shared randomized order is not evidence that positional bias was eliminated.

The optional offline helper changes the review contract and order control. Choose it explicitly when useful, then read `contracts.md` and retain all three original review judgments alongside its required structured reasons/evidence gaps. Balanced five-by-five provides one rotated packet per critic; paired mode compares reversal with separate fresh contexts. These adaptations must be reported. `state: complete` means valid judgments arrived, not that the advice is true. Balanced mode reports `within_reviewer_reversal: not_performed`.

## Checked synthesis

Use a separate fresh Chairman context with all drafts, restored lens identities, reviews and independently checked facts. Check the decisive facts or tests. Deliver where supported arguments converge, where they conflict, newly exposed omissions, the resulting recommendation or unresolved tie, and one feasible next step. Preserve minority evidence and missing information. State the five drafts/five reviews actually completed and same-model scope. Agreement alone must not raise factual confidence. Do not add another round or framework automatically.
