# Source fidelity

nstack pins source revisions and verifies their inventories before building.
Natural skill names do not change source identity. Full selected support,
licenses and source records travel with each installed bundle. Original
catalog activation rules remain controlling.

Most entries retain an upstream SKILL method. Tools without an upstream skill
need a native entrypoint that loads their actual version-matched source guides;
that entrypoint is authored integration, not an untouched upstream skill.
The catalog's delivery label alone does not describe every generated file.
Inspect the installed source/port receipt and actual content.

Native ports replace unsupported host commands and paths, preserve model and
effort, and remove incidental credential access, global setup or external
side effects. They must retain useful domain procedures. For example, OfficeCLI
ports retain the actual document, spreadsheet and presentation operations;
Postgres references retain concrete SQL and plan inspection. An archived
original alone does not justify removing the active method.

Changed originals, source/adapted hashes and patches are retained where the
port records them. Some earlier ports record transformations in the builder
rather than a standalone patch. A content seal detects changed bytes; it does
not establish that the adaptation is semantically correct. Compare the actual
pinned source and generated output when reviewing a method.

Reference-only and rejected candidates remain outside skill discovery. A
full source archive is not permission to activate sibling tools or runtimes.
Private source packs are used when redistribution rights are absent; public
nstack contains pinned fetch manifests rather than restricted source material.
See [Council](COUNCIL.md) for concrete examples.

Use [SkillSpector](SKILLSPECTOR.md) for explicit source audits. Keep integrity,
static findings, source review and real behavior tests distinct. Preserve
coverage limits and failed checks; neither a clean pattern scan nor a loader
count proves every capability works on every task.
