# Set up nstack in your own host

Paste the prompt below into Codex or Claude Code on your Mac. It installs the
shared methods through that host's adapter and commissions useful tools against
your machine. It does not copy the author's accounts, preferences, vault or
private runtime index. All methods being available does not mean every heavy
runtime should run or be downloaded.

The base collection has 170 methods. The complete optional selection below adds
21, including 01 and Craft Anything. Five academic methods use CC BY-NC 4.0;
omit `--academic-research` unless your intended use is covered. Other third-party
and runtime terms remain independent. A method install and a commissioned,
working runtime are separate results.

## Maintainer checks

The prompt is a commissioning instruction, not an unattended wizard. It must
use the actual checkout's supported commands and keep the user's authority.
Claude's file adaptation and transactions are covered by isolated tests;
the friend's normal fresh Claude session still supplies native loading and
model/tool evidence. Source and runtime checks on one Mac are not acceptance
for another Mac's permissions, hardware or accounts.
